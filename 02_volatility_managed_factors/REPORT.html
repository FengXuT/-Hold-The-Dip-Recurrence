1. 研究问题与复现范围

动量策略买入过去表现较好的股票、卖出过去表现较差的股票。市场剧烈反弹时，先前跌幅较大的股票可能反弹更快，动量的空头部分随之承受损失。原研究关注一个简单的仓位规则：依据最近的风险水平，每个月调整一次因子敞口。

本文覆盖原文 Table 1 的六因子绩效、实时组合、显著性和最大损失，Table 2 的精确收益分解，以及 Figure 1 的分组三分位结果；同时重建作者公开附图中的动量累计曲线。输入全部来自 Kenneth French 免费因子数据。原文后半部分以 CRSP 个股资料研究动量的市场 beta，属于另一项个股层面的机制检验。

六个因子分别是市场超额收益 Mkt-RF、规模 SMB、价值 HML、盈利 RMW、投资 CMA 和动量 Mom。前五个来自五因子文件，动量来自单独的动量文件。样本从 1963 年 7 月开始，前 120 个月用于积累估计历史，正式持仓从 1973 年 7 月开始。

2. 从原始数据到每月持仓

先把“收益”和“风险”放到各自对应的数据上

每个月赚取的因子收益取官方月度文件；每天的因子收益用于估计方差。月收益和日风险序列在月末日期对齐。源文件以百分数表示收益，读入后统一除以 100。当前官方输入文件使用 2026 年 9 月数据版本，本次固定取到 2026 年 8 月末，共 758 个月。

用最近的日收益估计下个月的风险

主规则对每日收益的平方做指数加权平均，半衰期为 21 个交易日。较新的观测权重更大；约一个月以前的观测权重衰减一半。取月末估计值乘以 21，得到月度风险信号。作为对照，传统规则使用上个月日收益相对该月均值的平方离差之和。

λ = 2^(−1/21) σ²[d] = λ × σ²[d−1] + (1−λ) × r[d]² S[m] = 21 × σ²[该月最后一个交易日]

风险越高，次月仓位越低

月 m 的仓位在上月末确定。缩放常数 c 使用当时已经积累的历史估计，分母是历次“月收益 ÷ 前月风险信号”的标准差。缩放估计从 1963 年 8 月起具备前月风险信号的月份开始。仓位上限为 1.5。仓位计算从预热期的最后一个月开始，给正式首月提供前期仓位，因此第一笔换仓成本也能按同一规则计算。

c[m−1] = sd(f[1…m−1]) / sd(f[s] / S[s−1], s ≤ m−1) w[m] = min(c[m−1] / S[m−1], 1.5) 净收益[m] = w[m] × f[m] − 0.0014 × |w[m]−w[m−1]|

每单位仓位变化收取 14 个基点。例如仓位从 0.8 调整到 0.5，成本为 0.0014 × 0.3，即当月收益的 0.042%。这项成本对应因子敞口调整。研究直接使用 French 已构造的多空因子收益。

5. 改善从哪里来：把收益拆开看

平均管理后收益可以精确拆成三项：恒定平均仓位带来的收益、仓位与因子收益的协方差、仓位调整成本。协方差为正，意味着较高仓位平均对应较好的收益月份；协方差为负，则表明较低仓位平均对应较好的收益月份。

平均净收益 = 平均仓位 × 平均因子收益 + Cov(仓位, 因子收益) − 平均成本

1973—2016 年，动量的恒定仓位项为年化 6.02%，择时协方差增加 2.46 个百分点，成本消耗 0.23 个百分点，得到 8.24% 的平均净收益。2017—2026 年，相同三项为 1.04%、1.05 和 0.14 个百分点，得到 1.94%。两段时期的动量择时协方差均为正。

7. 复现时做了哪些检查

检查从数据覆盖开始：四个文件分别识别日/月区段，统一单位，固定 1963-07—2026-08 的研究窗口。随后用递推算例核对 EWMA，再把 2008 年末及之后的收益、风险全部替换，检查此前仓位保持一致。成本核对直接从“仓位 × 当月收益 − 调整费用”重建净收益，12 组平均收益分解都在浮点精度内相等。

显著性沿用论文的学生化圆形区块重采样：区块长 12 个月，4,999 次，随机种子 20260928；638 月主样本每次抽取 54 个完整区块，共 648 个观测。每次检验单独重置种子，随后对六因子做 Holm 校正。这个完整区块约定和第一期成本的处理，会影响更细的 p 值与收益对照。

对照程序直接读取作者的 LaTeX 印刷表，以及保存到四位小数的参考 CSV。这样可以同时检查论文展示结果和更细的小数差异。参数始终采用论文的 21 日半衰期、1.5 倍上限及 14bp 成本，2017 年以后的结果另外列出。

8. 如何重新运行与阅读输出

在本项目文件夹安装 requirements.txt 中的依赖，按以下顺序运行。前两个脚本负责准备输入和计算；后三个分别核对作者实现、检验原表误差并生成这份报告。

python -m pip install -r requirements.txt
python download_data.py
python run_research.py
python verify_implementation.py
python compare_results.py
python build_report.py

原始文件及下载来源保存在 data/，月度路径、逐项误差和中间统计保存在 outputs/。REPORT.html 已嵌入全部图表，下载后可以离线阅读。初次下载后默认复用快照；download_data.py --refresh 会重新获取官方输入。
