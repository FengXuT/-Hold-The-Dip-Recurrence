从企稳到卖压衰竭：
下行压力衰减与新低停止的双因子实验

在华泰期货“连续大跌后等待七日企稳”的框架上，本研究增加两个入场条件：近期下行压力已经降低，以及价格低点已经稳定三日。研究重点是观察这些条件能否改善交易时机，同时保留大反弹阶段的收益。

主要结果：2022年7月22日至2026年8月31日，双因子组合完成13笔交易，年化收益15.58%，夏普1.466，最大回撤6.56%；原企稳策略分别为15笔、14.98%、1.332和6.62%。平均名义敞口由29.10%降至25.11%。净利润增加363.63万元，改善主要来自2023年一次亏损交易的跳过与2025年1月入场时机的调整。

基准来自华泰期货研究院2026年9月1日正式研报，其完整复现见原研报复现报告。本报告讨论的是在既有复现样本上的自主因子扩展，所有主参数在本次首次回测前固定，后续网格用于观察邻域变化。

1. 为什么选择这两个因子

原企稳条件只比较等待期末与大跌触发日的收盘价。两条价格路径即使终点相同，过程也可能不同：一条已经停止探底，另一条刚刚创出新低后快速拉回。观察下行波动与最低价出现的时间，可以补充收盘价比较的信息。

前一轮实验曾用总波动下降来缩减仓位，夏普降至1.17。2024年2月的强反弹使总波动升高，这笔交易却贡献了1441.36万元。因此，本次专门度量下跌方向的波动，并把因子用于入场筛选。

2. 因子与交易规则

因子一：下行压力衰减

日收益记为r，先把正收益置零，再计算平方收益的均值平方根。这样，上涨产生的波动会保留为零，下跌才贡献压力。

D(n,u) = sqrt[ mean(min(rᵢ,0)²), i=u−n+1,…,u ]
下行压力比 P = D(3,确认日) / D(20,触发日前一日)
通过条件：P ≤ 1

分母使用大跌触发日之前20个交易日，分子使用确认日及此前两日。P≤1表示近期下跌压力已经回到触发前的水平或更低。窗口内所有交易日都进入平均值，上涨日贡献零。

因子二：新低停止

A = 确认日 − [触发日至确认日期间最后一次最低价的日期]
通过条件：A ≥ 3个交易日

价格采用每日最低价；若最低价重复出现，取最后一次。A≥3意味着最低点之后已有三个交易日守住这一低点。

从条件到可执行策略

  1. 中证1000五日收益低于−4.92%，记录触发日t；到t+7收盘检查原企稳条件Cₜ₊₇≥Cₜ。
  2. 原条件通过后，分别测试压力比P≤1、守底A≥3，以及两者同时通过的组合。
  3. 条件通过则下一交易日开盘入场；未通过时，后续交易日继续评估各自七日前形成的新信号。
  4. 按原规则持有20个交易间隔后开盘退出；同一时刻持有一笔多头，平仓当日收盘可重新确认信号。

主实验统一采用固定七日等待期与20日持有期。初始资金1亿元，单笔保证金预算1200万元；使用剩余期限严格超过40个交易日的最近到期实际合约，整数手数向下取整。IM开仓保证金在2023年5月5日前取15%，之后取12%；双边手续费各万分之0.3，空仓资金收益取零。样本包含能在截止日前完成持有期的交易。

绩效采用250个年度交易日；年化收益为净值几何增长率，波动为日收益样本标准差年化，夏普为（年化收益−2%）/年化波动。沿用这些口径，基准回放逐日净值及全部15笔交易与原复现一致。

2023年5月，原交易的下行压力比为1.416，组合跳过这笔亏损143.17万元的交易。2024年11月，确认日刚出现等待期最低价，组合选择继续等待，随后少获得原交易的32.94万元盈利。

2025年1月，原确认日距最低价仅一天；组合等到新的信号通过后，于1月17日入场，较基准晚两个交易日，净收益从867.29万元升至1191.97万元。最近到期合约也从IM2503变为IM2506。按相同延后日期仍交易IM2503测算，净收益为1177.35万元；约310.06万元改善来自交易时点及相应开仓手数变化，约14.62万元来自本例合约选择变化。

2025年4月，原信号的下行压力比为1.085，组合在下一日的新确认通过后入场，这次延后少获得71.28万元。四处变化合计增加363.63万元净利润。

筛选与继续等待的作用不同

将原来的15笔交易固定，只删除未通过双因子的交易，可留下11笔，年化收益为12.49%，净利润为5989.36万元。允许后续新信号继续确认后，组合完成13笔，年化收益15.58%。这说明本次结果的关键是“条件未成熟时继续观察，成熟后参与”，单纯删除交易会错过2025年1月和4月的修复行情。

7. 结论与后续研究

这次实验支持把“企稳”进一步拆成“收盘恢复、下行压力减弱、低点稳定”三个条件。双因子组合在中证1000样本中，以较低平均敞口获得略高收益和夏普；最大回撤改善较小。逐笔归因显示，收益提升更依赖信号延后后的重新入场，尤其是2025年1月的调整。

后续优先保留下行压力因子作为通用候选，连续守底作为中小盘的附加条件；沿用本次固定参数，按新增时间段累计事件。研究记录同时保留未通过信号、后续重新入场、名义敞口及每笔收益，以继续检验等待带来的收益与机会成本。

8. 如何复算

首次准备数据时，在上级目录按README安装依赖并运行download_data.py；之后在本目录执行：

python backtest.py
python build_report.py

backtest.py生成每日净值、全部候选、逐笔交易、等敞口对照、年度利润、四指数、参数邻域和成本压力结果。程序检查基准逐日回放、逐笔现金对账，并把行情截断至两个历史日期，核验四种策略的历史因子和已完成交易保持一致。build_report.py从这些输出生成本报告。

数据：中证指数官方OHLC、国证指数交易日期、新浪逐合约期货日线；历史保证金与基准规则沿用上级复现项目。研究区间：2022-07-22—2026-08-31，997个交易日。报告生成日期：2026-11-10。方法与运行说明见本目录README。
