# 双因子策略：时点修正与时间留出检验

[完整报告](REPORT.html) · [原研报复现](../README.md)

本项目在华泰期货研报的七日企稳条件上，增加下行压力衰减和连续三日守底。当前版本已修正区间起止边界与开盘价定仓，并补充训练期封存、时间留出及成交方式比较。

## 修正后的原区间结果

2022-07-22至2026-08-31，初始资金1亿元，保证金上限1200万元。

| 策略 | 笔数 | 年化收益 | 最大回撤 | 夏普 | 平均名义敞口 |
|---|---:|---:|---:|---:|---:|
| 原企稳条件＋修正执行 | 15 | 14.93% | 6.63% | 1.331 | 29.01% |
| 下行压力衰减 | 14 | 15.05% | 6.56% | 1.371 | 27.02% |
| 连续3日守底 | 14 | 15.43% | 6.63% | 1.425 | 27.03% |
| 双因子组合 | 13 | 15.55% | 6.56% | 1.468 | 25.04% |

## 问题与修正

- 旧候选逻辑要求完整平仓日期位于样本内。截到2024-02-19，会删除当日已经确认、计划3月19日退出的合格信号。现按日保留订单、持仓和收盘估值。
- 旧手数用次日实际开盘价计算。2026-04-02旧公式为67手，而确认日已知价格对应66手。现按确认日合约收盘价定仓，并预先设置保证金上限对应的开盘限价。
- 开盘价高于已提交限价则撤单，收盘继续评估新信号；成交价满足限价时才执行。报告同时展示把保证金作为目标、开盘市价成交的对照。
- 原核验只比较已完成交易。现比较五个截止点的全部已形成订单和净值前缀，并扰动未来价格检查过去决定与训练选参保持一致。

- 复查发现区间首日遗漏前一收盘已确认的订单；现先初始化前一收盘的决策，再从首日开盘执行。13个实际开仓日及首日限价撤单情景均通过独立窗口回归检查。
- 无交易区间CSV保留完整表头；单日窗口的波动率、夏普留空，收益与回撤照常计算。

## 因子与交易规则

P为确认日前3日的下行收益均方根，除以触发日前20日的同类指标，要求P≤1。正收益置零，均值包含全部窗口交易日。

A为确认日距触发日至确认日期间最后一次最低价的交易日数，要求A≥3；最低价并列时取最后一次。

原五日收益阈值−4.92%、七日确认、20日持有及双边各万分之0.3手续费继续用于主历史对照。手数按确认日已知价格取整，次日开盘按照预设限价执行；评估区间从首日开盘开始，读取前一收盘形成的订单，期末持仓按收盘估值。

## 时间留出与过拟合检查

训练区间2022-07-22至2023-11-30，仅用331个训练期五日收益估计5%分位数，阈值−4.396%。九组训练参数按夏普选择，至少要求三笔已平仓交易；选中P≤0.75、A≥3。

保留21个交易日的间隔后，测试2024-01-02至2026-08-31：

| 策略 | 年化收益 | 最大回撤 | 夏普 |
|---|---:|---:|---:|
| 同训练阈值基准 | 18.36% | 7.31% | 1.265 |
| 固定因子1.0/3日 | 19.04% | 7.31% | 1.364 |
| 训练选择0.75/3日 | 12.87% | 9.27% | 0.920 |

训练选择仅依靠3笔交易，守底2、3、4日的训练结果完全相同。逐年留出中，2024年与2026年选出的0.75阈值表现较弱，2025年选出的1.0阈值表现较好。报告保留全部结果。

因子提出时已经查看原研究区间，当前定位为历史时间留出重建。2026-09-01至11-09的新区间也参与了执行约束修正，报告列为新增区间回放。完整前向记录从2026-11-10规则冻结后开始积累。

## 运行

先在上级目录安装`requirements.txt`并运行`download_data.py`，准备原研报数据快照。然后在本目录执行：

```bash
python fetch_evaluation_data.py
python backtest.py
python audit_validation.py
python build_report.py
```

原复现数据位于上级`data/raw/`；本次独立评估快照位于本目录`data/evaluation/`，取数截至2026-11-09。期货原始接口可能包含更晚报价，计算按区间日期读取。
