# 下行压力衰减＋新低停止：自主因子回测

基于上级华泰期货研报复现，本项目检验两个新增入场条件，并独立生成一份结果报告。

[阅读因子回测报告](REPORT.html) · [原研报复现](../README.md)

## 结果

研究区间为2022-07-22至2026-08-31，997个交易日，实际交易IM交割合约。

| 策略 | 笔数 | 年化收益 | 最大回撤 | 夏普 | 平均名义敞口 |
|---|---:|---:|---:|---:|---:|
| 原企稳策略 | 15 | 14.98% | 6.62% | 1.332 | 29.10% |
| 下行压力衰减 | 14 | 15.10% | 6.56% | 1.371 | 27.11% |
| 连续3日守底 | 14 | 15.46% | 6.62% | 1.424 | 27.10% |
| 双因子组合 | 13 | 15.58% | 6.56% | 1.466 | 25.11% |

组合相对基准增加净利润363.63万元，改善集中在2023年一次亏损交易的跳过和2025年1月的延后入场。2024年11月和2025年4月的筛选、延后分别损失部分收益。全部逐笔归因见报告。

固定原15笔事件后仅作删除筛选，组合留下11笔交易；逐日继续检查后续新信号，才会形成主实验的13笔交易。报告同时比较这两种处理。

## 固定规则

保留原策略的五日大跌阈值、七日企稳确认和20日持有期，增加：

1. 下行压力比P：确认日最近3日的下行收益均方根，除以触发日前20日的同类均方根；要求P≤1。正收益置零，均值仍按窗口内全部交易日计算。
2. 守底天数A：从触发日至确认日期间最后一次最低价，到确认日经过的交易日数；要求A≥3。最低价并列时取最后一次。
3. 分别回测两个单因子与AND组合。未通过的信号被跳过，之后逐日评估新的七日确认信号。

主参数P≤1、A≥3在本次首次回测前固定。另展示P上限0.75/1.0/1.25与守底2/3/4日的九组邻域结果。

资金、合约期限、整数手数、历史保证金、手续费和绩效公式沿用上级项目；本次研究属于既有复现样本内的因子扩展。

## 运行

首次准备环境与数据，在上级目录执行：

```bash
python -m pip install -r requirements.txt
python download_data.py
```

然后进入本目录：

```bash
python backtest.py
python build_report.py
```

无需重新运行上级完整复现；因子脚本直接读取上级`data/raw/`，并调用上级的行情读取、基准回放和绩效计算函数。

## 文件与输出

- `backtest.py`：候选信号、四种策略、每日净值、等敞口比较、跨指数、参数邻域、成本压力和历史截断核验。
- `build_report.py`：从本次计算输出生成独立HTML报告。
- `REPORT.html`：内嵌图表，可离线浏览。
- `outputs/`：运行生成的CSV与JSON，由Git忽略。

关键输出包括：

| 输出 | 内容 |
|---|---|
| `all_candidates.csv` | 全部30个原企稳条件合格的候选及两个因子值 |
| `*_trades.csv` | 各策略实际交易、因子、手数与净收益 |
| `nav.csv` / `exposure.csv` | 每日净值与开仓名义敞口 |
| `baseline_event_diagnostics.csv` | 固定原15笔交易的因子诊断 |
| `fixed_event_filter.json` | 固定事件筛选的结果 |
| `matched_exposure.csv` | 事后将基准每日净损益等比例缩放的等平均敞口对照 |
| `trade_attribution.csv` | 组合与基准不同交易月份的净利润差额，由报告脚本生成 |
| `january_decomposition.json` | 2025年1月延后入场时，交易时点与换约的收益拆解 |
| `annual.csv` / `cross_index.csv` | 年度表现与四指数对照 |
| `sensitivity.csv` / `cost_stress.csv` | 九组参数及更高手续费、单边1点冲击成本结果 |
| `validation.json` | 基准回放、现金对账和历史截断检查结果 |

回测首先逐日、逐笔还原上级基准。之后把行情分别截断至2024-06-28和2025-06-30，核对四种策略的历史候选因子与已完成交易。所有情景均核对每日损益和逐笔净收益之和。

报告进一步讨论等敞口比较、收益集中程度、逐年差异及跨指数适用性，后续可沿用固定规则积累新的时间段结果。
