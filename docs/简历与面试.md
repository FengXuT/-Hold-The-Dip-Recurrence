# 简历与面试准备

## 项目名称

**抄底策略的有效性研究：AQR量化研究公开数据复现**

技术：Python、pandas、NumPy、Matplotlib、statsmodels；日频回测、OLS/HAC、Holm多重检验。

## 简历草稿

完成个人学习、重跑与讲解准备后，可按实际掌握程度使用以下内容：

- 基于AQR《Hold the Dip》构建196组抄底规则，整理1965—2025年15,288个交易日的标普500价格与现金利率，完成信号、成交、持有和资金复利的日频回测。
- 使用OLS、HAC标准误和Holm多重检验分析择时收益；实测平均夏普0.168，买入持有0.254，171组规则落后，平均年化alpha约0.086%，并比较执行时点、重复信号、成本及市场阶段的影响。
- 产出可复运行代码、原始数据快照、完整结果表、逐日仓位、交易示例、4张研究图与中文说明，分析公开数据复现与原文之间的数值差异。

若版面只容纳一条：

> **AQR抄底策略研究复现｜Python**：基于60年日频数据实现196组抄底规则，结合市场回归、HAC标准误、多重检验及成本敏感性评价择时表现，完成可复运行代码、结果图表与复现差异分析。

## 一分钟讲述

我研究的是一个常见想法：市场下跌以后买入，是否能比持续持有股票取得更好的风险调整后回报。我选择AQR在2025年底发布的一篇文章，按照跌幅、回看周期和持有周期建立196组规则，用公开标普500价格和现金利率进行回测。

实现里我重点处理了信号和成交的时间关系：收盘观察到下跌信号，下一交易日收盘才成交。之后比较全部规则的夏普，并对超额收益做市场回归，使用HAC标准误和多重检验评价alpha。

结果是多数规则的风险调整后表现较弱，平均夏普0.168，买入持有0.254。数值和原文存在差异，所以我进一步比较了信号处理、执行延迟和成本，发现整体方向相近。这让我对复现中的数据口径、交易规则和统计证据有了具体理解。

## 面试中可能追问的内容

| 问题 | 回答重点 |
|---|---|
| 为什么用价格收益？ | 原文长样本采用这个口径；代码和结果表按价格收益解释。含分红ETF是可以另外展开的研究问题。 |
| 跌幅怎么定义？ | 当前收盘相对L日前收盘的累计收益，低于负阈值触发。 |
| 如何检查未来信息？ | 用下一收盘成交；手工序列检查延迟；追加未来数据后历史仓位保持相同；再用持有周期独立重建一条规则。 |
| 持仓中再次触发怎么办？ | 主实验忽略，敏感性实验延长到期时间；两者的仓位路径和结果都保留。 |
| 为什么同时看夏普和alpha？ | 前者衡量超额收益相对风险，后者通过市场回归分析控制平均市场暴露后的截距。 |
| HAC做了什么？ | 对异方差和时间相关调整协方差估计；本项目用21阶滞后。 |
| 为什么校正多重检验？ | 同时看196条规则时，单项p值容易出现偶然的较小值，因此同时报告Holm结果。 |
| 你的结果和原文为何不同？ | 数据源、现金期限、固定交易日换算、执行和重复信号处理都有口径差异；用敏感性结果说明已观察到的影响。 |
| 项目最大的收获是什么？ | 将交易直觉变为可检查的实验，并从收益、仓位、风险、统计和实现角度解释结果。 |

## 面试前的个人练习

先手算一个包含下跌、信号和63日持有的例子，再运行项目并从交易清单挑一条核对。接着读懂热力图、夏普定义和alpha回归。最后用自己的话解释一项数值差异，以及你准备怎样进一步研究它。
