# 复现流程：从一篇量化研究文章到可以讲清楚的个人项目

## 1. 研究的问题与交付目标

这个项目研究一个常见的交易想法：市场跌了一段之后买入，持有一段时间，是否比持续持有股票更有效？我们用同一段市场历史比较大量事先给定的抄底规则，观察收益、风险和市场暴露，再检验收益中有多少来自择时。

选择的原文是 AQR《Hold the Dip》，发表于 **2025 年 12 月 1 日**，属于 Alternative Thinking 2025 Issue 4。[官方介绍](https://www.aqr.com/insights/research/alternative-thinking/hold-the-dip)｜[原文 PDF](https://www.aqr.com/-/media/AQR/Documents/Alternative-Thinking/AQR-Alternative-Thinking---Hold-the-Dip.pdf?sc_lang=en)。项目名称采用“机构量化研究复现”，突出研究过程和公开数据验证。

复现围绕原文 Exhibit 3 和 Exhibit 4：抄底策略的夏普比率比较，以及控制市场暴露后的 alpha 回归。额外做执行延迟、重复信号、交易成本、分阶段表现和文章发布后检验。阅读顺序建议为：本文 → `outputs/复现结果.md` → `research_walkthrough.ipynb` → `run_research.py`。

## 2. 为什么选这一篇

它足够新，参数网格和评价对象又足够明确，个人可以用免费的公开日频数据开展研究。策略只有一个股票指数与现金，能把精力放在研究问题本身：信号如何形成、何时交易、怎样评价一个长期空仓的策略、如何处理大量参数组合。

这类项目的价值在于把一个想法变成可核对的实验。最终成果包括原始数据快照、清洗数据、196 组参数结果、逐日仓位、结果图、可运行代码和研究说明，适合在面试中边看图边解释。

## 3. 先明确复现范围

| 项目 | 原文设定 | 本项目设定 |
|---|---|---|
| 主样本 | 1965-01-01 至 2025-09-30 | 同一日历区间，首个交易日为 1965-01-04 |
| 股票收益 | S&P 500 价格收益 | Yahoo Finance `^GSPC` 收盘价的价格收益 |
| 现金收益 | ICE BofA 3M T-Bill | French 日频 RF，1M T-Bill 口径 |
| 参数 | 4 种跌幅 × 7 种回看 × 7 种持有 | 使用相同网格，周期换算为固定交易日 |
| 重复信号 | 原文描述留有实现空间 | 主实验持仓中忽略新信号，另测持仓展期 |
| 成交时点 | 原文未具体展开 | 信号后下一交易日收盘成交，收益仓位滞后两行 |
| 费用 | 原文采用毛收益 | 主实验毛收益，另测单边 5/10/25 bps |
| alpha 标准误 | 原文未说明具体估计器 | 同时报普通 OLS 和 HAC(21) |

这些具体实现决定了复现的精度。结果表会同时列出原文目标与本次实测值，再解释差异的可能来源。

SG Trend 的比较、总回报口径的子样本和个股附录留作后续研究。本项目另设一条简单的 252 日趋势基线，便于理解方向性择时。

## 4. 获取并理解数据

### 4.1 股票价格

数据来自 [Yahoo Finance 的 S&P 500 页面](https://finance.yahoo.com/quote/%5EGSPC/)。`download_data.py` 使用其公开 chart JSON 端点，下载 1963 年起的日频数据，处理后截止到 2026-09-30。1963—1964 年只提供回看窗口，主实验从 1965 年开始建立仓位。

原始文件 `data/raw/gspc_daily.json` 保留响应内容。代码把时间戳转换为纽约交易日期，读取 `close`，再计算：

`r_market[t] = close[t] / close[t-1] - 1`

原文长样本采用价格收益，因此这里也按价格收益复现；项目中的股票净值按照该口径解释。日历日期严格裁切，下载端点额外返回的边界数据会在清洗时处理。

### 4.2 现金利率

数据来自 [Kenneth French 官方因子说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/f-f_factors.html) 与[日频文件](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/F-F_Research_Data_Factors_daily_CSV.zip)。项目只使用其中的 RF 列。原始数值以百分数表示，读入时除以 100。

官方文件将 RF 定义为能在当月交易日上复利到月度短期国债收益的简单日利率。2024 年 5 月及以前来自 Ibbotson，之后来自 ICE BofA 的 1M T-Bill 指数。它与原文的 3M 口径存在期限差异。

### 4.3 入口审计

`load_data()` 集中检查日期唯一性、价格排序、价格完整性、正价格、现金利率对齐和区间覆盖。进入回测之后直接使用整理好的数组。

清洗结果写入 `data/processed/market_daily.csv`。`data/raw/download_manifest.json` 记录真实下载 URL、时间、文件大小和下载方式。本次 Stooq 端点返回浏览器验证页面，因此实际采用 Yahoo 的 JSON 数据，并保存了原始快照。

## 5. 把“逢跌买入”写成一条规则

### 5.1 参数网格

| 维度 | 值 |
|---|---|
| 跌幅 D | 5%、10%、15%、20% |
| 回看 L | 5、10、15、21、63、126、252 个交易日 |
| 持有 H | 21、42、63、126、252、756、1260 个交易日 |

总数为 `4 × 7 × 7 = 196`。每月按 21 个交易日、一年按 252 个交易日换算。固定参数网格全部进入结果表。

在交易日 t 收盘后，计算：

`lookback_return[t] = close[t] / close[t-L] - 1`

当 `lookback_return[t] <= -D` 时触发信号。这里衡量的是相隔 L 个交易日的累计跌幅。例如一个月前为 100、今天为 89，则 21 日跌幅是 -11%，可触发 10% 规则。区间内价格峰值不参与这条信号的计算。

### 5.2 主实验的持仓规则

空仓且触发信号时安排买入；持有 H 个日收益区间后卖出；持有期间的新信号忽略。股票仓位只有 0 和 1，其余资金赚取现金利率。

**时间线例子：**周一收盘形成信号，周二收盘买入，周三的收益记录第一次包含股票收益。若 H=2，就赚取周二收盘到周三收盘、周三收盘到周四收盘这两个收益区间，周四收盘卖出。代码里 `market_return[t]` 表示前一收盘到当前收盘的收益，仓位相对信号滞后两行。

这个设定允许根据已经观察到的收盘信号，在下一次收盘安排交易。收盘价仍是日频研究的成交近似，费用分析进一步考察成交摩擦。

`positions()` 用一个剩余持有天数计数器表达这件事，直接输出逐日仓位。由于它同时用于所有参数组合、执行敏感性和时间逻辑自检，单独保留这个函数方便核对。

### 5.3 资金与费用

设 `w[t]` 为日收益区间内的股票仓位，`rf[t]` 为现金日收益：

`r_strategy[t] = rf[t] + w[t] * (r_market[t] - rf[t])`

每个策略账户初始资金都是 1，满仓使用现有资金，卖出后资金进入现金。组合持续复利，主实验采用固定的 0/1 股票暴露。

单边成本 c 用仓位变化计量：

`turnover[t] = abs(w[t] - w[t-1])`

`r_net[t] = r_strategy[t] - c * turnover[t]`

5 bps 为单边 0.05%，完整买卖一次约 10 bps。成本记在新仓位生效的收益区间，样本末以市值计价。`annual_turnover` 是每年单边换手，买入和卖出各计一次。两个持有周期在同一次收盘衔接时，维持股票净仓位；费用按净仓位变化计，`entries`统计股票净仓位从0变为1的次数。

## 6. 怎样评价结果

### 6.1 收益与风险

- **年化收益 CAGR：**`最终净值 ** (252 / 交易日数) - 1`，描述资金复利增长。
- **年化波动率：**日策略收益的样本标准差乘以 `sqrt(252)`。
- **夏普比率：**`mean(r_strategy-rf) / std(r_strategy-rf) * sqrt(252)`。
- **最大回撤：**净值相对此前最高净值的最大下降幅度，初始净值 1 计入峰值。
- **平均仓位：**样本内股票仓位均值，用来理解股票暴露程度。

股票投资时间少会直接影响累计收益，因此同时观察夏普、仓位和 alpha，更容易理解收益来源。现金组合相对自身基准的超额收益为零，夏普在输出中记为空值。

### 6.2 用市场回归理解择时

对每条规则估计：

`strategy_excess[t] = alpha_daily + beta * market_excess[t] + residual[t]`

`alpha_ann = alpha_daily * 252`。beta 反映对市场收益的平均敏感程度；alpha 描述回归在该样本中给出的截距收益。代码保留普通 OLS 的 t 值，便于与原文图示讨论，并以 Newey–West HAC、21 阶滞后、有限样本修正和正态近似 p 值作为本项目主推断口径。

HAC 用于处理残差的异方差和时间依赖。21 是事先选定的一个交易月尺度。若进一步研究长持有期的显著性，可以单独考察带宽变化或采用时间块自助法，形成下一阶段的问题。

### 6.3 同时检验 196 条规则

完整报告每条规则的 p 值，再对 196 个 HAC p 值进行 Holm 校正。这样可以同时回答：单个参数的统计表现如何，以及在整个参数搜索家族中是否有足够证据。Holm 控制整个检验家族出现假阳性的概率，适合这里需要整体评价的场景。

热力图把四种跌幅做等权平均，用回看期和持有期展示结构。196 组完整结果保存在 `grid_results.csv` 中，能逐项追溯。

## 7. 在什么条件下重复检查

### 执行方式

`implementation_sensitivity.csv` 保留三种情况：主实验的“忽略重复信号、滞后两行”，更理想化的“滞后一行”，以及“新信号将到期时间延后、滞后两行”。滞后一行代表根据信号收盘价立即建立仓位的研究近似，可帮助比较成交时点的影响。

### 交易成本

单边成本分别为 0、5、10、25 bps，所有 196 条规则都计算一次。主图中买入持有参照线采用毛收益，成本对比表保留明确标记。

### 历史阶段

分为 1965—1989、1990—2009、2010—2025Q3。切换阶段时延续原有仓位，只在统计评价时切片，便于观察相同规则经历不同市场的表现。

### 文章发布之后

时间外检查使用 **2025-12-02 至 2026-09-30**。参数、资金规则和仓位都从历史一路延续，这段数据只进入单独的阶段表。文章样本结束到发布之间的 2025 年 10—11 月用于延续仓位。

报告把这个窗口的长度和实际持仓比例一起呈现，判断以观察到的区间为范围。进一步积累更多发布后交易数据，可以更新同一张结果表。

### 简单趋势基线

当价格高于 252 个交易日前的价格时持有股票，否则持有现金，同样滞后两行。它只用一个指数，可以直观解释顺势与抄底在仓位路径上的差别。

### 等权规则组合

把初始资金等分给 196 个规则，并每日再平衡回等权子账户，则组合的单日毛收益是 196 个策略单日收益的算术平均。图中 `equal_weight_196` 按这个定义计算，用于查看整组规则的平均暴露路径。它另有再平衡成本问题，所以结果图将其作为毛收益研究基线。

## 8. 实际运行顺序

推荐 Python 3.12 或 3.13。以下命令在这个项目目录内执行。

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Linux / WSL 可使用 source .venv/bin/activate
python -m pip install -r requirements.txt
python download_data.py
python run_research.py --self-check
python build_report.py
```

`download_data.py` 默认复用已有快照。希望重新下载时使用 `python download_data.py --refresh`，再依次运行研究和报告脚本。网络需要能访问数据源；也可从脚本所列 URL 下载同名文件放入 `data/raw/`。

本次实际使用 Windows Anaconda Python 运行，原因是本机 WSL 直连公开站点出现 TLS 连接错误。原始下载由 Windows PowerShell 完成，Python 读取缓存执行全部计算。`outputs/summary.json` 记录本次实际依赖版本和执行时间。常规安装所需命令也保存在 README 中。

## 10. 代码是怎样验证的

自检围绕容易影响金融结论的地方设置：手工短序列验证信号延迟和持有长度；重复信号例子验证忽略与展期差别；无信号例子检查空仓；从实际仓位重建示例日收益；验证 196 组成本升高后 CAGR 均未上升；截断未来数据后验证历史仓位不变。

输出的逐日仓位与收益让这些逻辑能被再次核对。报告生成程序直接读取研究输出，保持表格数值与结果文件一致。

## 11. 用这个项目准备面试

建议先掌握四个问题：

1. **研究问题是什么？** 抄底能否改善风险调整后表现，以及能否产生控制市场暴露后的收益。
2. **最关键的实现选择是什么？** 跌幅用窗口累计收益；下一交易日收盘成交；持有期内忽略新信号；现金赚取 RF。
3. **复现结果和原文差在哪里？** 用结果报告的对照表回答，说明数据和实施口径，再展示敏感性结果。
4. **自己的工作体现在哪里？** 数据处理、时间对齐、完整参数网格、回归、HAC 与多重检验、成本和分段评估，以及对数值差异的解释。

简历文字与讲述要以你亲自理解、运行并能解释的部分为依据。`docs/简历与面试.md` 提供了一份基于本次实测结果的草稿。
