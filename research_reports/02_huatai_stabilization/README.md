# 大跌后企稳再入场：华泰期货研报复现

复现华泰期货研究院李光庭的正式量化专题研报：**《大跌后应该如何抄底2.0？——左侧+企稳确认》**，封面日期 **2026-09-01**，官网上传日期2026-09-09。

- [官网原研报PDF](https://www.htfc.com/wz_upload/png_upload/20260909/1788943656749408f5b.pdf)
- [官网发布页](https://webtrade.htfc.com/main/a/20260909/80181909.shtml)
- [复现结果报告](REPORT.html)：下载后用浏览器打开，图表已内嵌，可离线阅读。

研究覆盖中证1000实际股指期货交易，以及中证500、沪深300、上证50的跨指数比较。

## 结果

回测区间为2022-07-22至2026-08-31。

| 指标 | 直接抄底原文 | 直接抄底复现 | 企稳策略原文 | 企稳策略复现 |
|---|---:|---:|---:|---:|
| 开仓次数 | 17 | 17 | 15 | 15 |
| 期末净值 | 1.64 | 1.63800 | 1.74 | 1.74507 |
| 年化收益 | 13.21% | 13.172% | 14.97% | 14.983% |
| 最大回撤 | 24.11% | 24.106% | 6.63% | 6.625% |
| 夏普 | 0.79 | 0.783 | 1.33 | 1.332 |

25组等待期与持有期组合的年化收益最大误差0.0494个百分点、回撤最大误差0.0553个百分点；四个指数的开仓次数均与原文一致。原图读取轨迹与复现曲线的相关系数分别为0.99969、0.99979。

## 运行

在本目录运行，使用Python 3.11及以上；本次验证环境为Python 3.13.9。

```bash
python -m pip install -r requirements.txt
python download_data.py
python reproduce.py
python check_results.py
python build_report.py
```

`download_data.py`跳过已有文件；需要重新下载时执行：

```bash
python download_data.py --refresh
```

首次运行需要联网。指数取数截止固定为2026-11-06，回测截止固定为2026-08-31；后续报价进入原始合约文件时，回测仍只使用研究区间的数据。

## 交易与统计口径

1. 中证1000五日收益低于−4.92%时触发信号；等待7个交易日，收盘价恢复至触发日收盘价以上，则下一交易日开盘入场。
2. 使用已经上市且剩余交易日严格超过40日的最近到期合约；开仓后第20个交易间隔结束时，在开盘平仓。2026-07-30入场对应2026-08-27退出。
3. 初始本金1亿元，单笔保证金预算1200万元；按开仓价格、合约乘数和保证金率向下取整计算手数。IM历史开仓保证金为15%，自2023-05-05起取12%；IC此前为14%，IF/IH为12%。
4. 双边手续费各万分之0.3，按逐合约收盘价估值，空仓资金收益取零。仓位采用固定初始资金预算。
5. 平仓当日收盘起可接受新确认；持仓期间触发、平仓后才完成企稳确认的信号仍有效。最后一笔须在样本截止日前完成退出。
6. 年化收益取250交易日的几何增长率，波动取日净值收益样本标准差乘√250，夏普取（年化收益−2%）/年化波动。

原文明确了价格信号、执行时点、资金预算与手续费；历史保证金由交易所通知补充，重复信号及统计细节通过交易次数、逐笔锚点、原图和整张参数表共同核验。

## 文件与输出

| 文件 | 作用 |
|---|---|
| `download_data.py` | 下载原研报、官方指数与交易日期、72个季度期货合约、4天中金所官方日行情及保证金通知 |
| `reproduce.py` | 主策略、直接抄底、四指数、25组参数 |
| `check_results.py` | 官方价格、历史截断和参数表对照检查；逐笔锚点与现金对账在回测中执行 |
| `build_report.py` | 读取计算输出，提取原图轨迹，生成唯一的HTML结果报告 |
| `REPORT.html` | 原理、流程、曲线对照、全部交易、参数与指数检验 |

运行后生成：

- `data/raw/`：原始文件；`sources.json`记录各文件来源URL。
- `outputs/nav.csv`：直接抄底和企稳策略的每日净值。
- `outputs/*_trades.csv`：信号日、确认日、开平仓日、真实合约、手数、五日跌幅及收益。
- `outputs/metrics.json`、`parameter_grid.csv`：主策略、跨指数与参数结果。
- `outputs/validation.json`、`curve_comparison.json`：核验与曲线误差。
- `outputs/source_curve_digitized.csv`：依据原图坐标轴读取的对照轨迹。

原始数据和运行中间输出由脚本生成，仓库保留代码、README和一份结果报告。报告覆盖期货部分；期权比较可继续补充逐执行价历史报价。

## 数据来源

指数OHLC来自[中证指数公司](https://www.csindex.com.cn/)，交易日期来自[国证指数](https://www.cnindex.com.cn/)，期货逐合约日线来自新浪。四天IM2303开盘/收盘价由[中金所官方历史日行情](http://www.cffex.com.cn/sj/hqsj/rtj/202301/30/20230130_1.csv)复核。15%→12%的保证金变化由[中银国际期货转发的中金所正式通知](https://www.bocifco.com/newsinfo.aspx?cid=3&id=48089)核验。

原图读取使用图6的可见轴刻度标定：横轴2023—2026年元旦，纵轴净值1.0—1.8。图像分辨率约每天一个横向像素，轨迹对比结合线宽与日期定位精度解读。
