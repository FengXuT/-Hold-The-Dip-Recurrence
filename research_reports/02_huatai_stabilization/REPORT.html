大跌后企稳再入场：
把“左侧抄底”拆成可以检验的信号

本项目复现华泰期货研究院李光庭于2026年9月1日发布的量化专题研报《大跌后应该如何抄底2.0？——左侧+企稳确认》，研究中证1000大跌后的入场时机。

阅读官网原件（15页） · 官网发布页。原件封面日期为9月1日，网站上传日期为9月9日。复现区间为2022年7月22日至2026年8月31日，共997个交易日。

主要结果。企稳策略复现出15笔交易，年化收益14.983%，最大回撤6.625%；原文分别为14.97%和6.63%。直接抄底的17笔交易及24.11%最大回撤也得到还原。25组参数的年化收益最大差异为0.049个百分点，最大回撤最大差异为0.055个百分点。

1. 这项研究想解决什么问题

大跌后的反弹具有吸引力，但入场过早会经历继续下跌。研报把入场分成两步：先用连续五日跌幅找出恐慌阶段，再观察七个交易日，检查价格是否恢复到大跌日收盘之上。由此，研究重心从“跌得多不多”转向“卖压是否缓和”。

2. 把文字规则还原成交易流程

  1. 在交易日t收盘，计算五日收益 Cₜ/Cₜ₋₅−1；低于−4.92%时记录大跌信号。
  2. 从t之后的下一交易日起等待七个交易日；若Cₜ₊₇≥Cₜ，则在t+8开盘买入。
  3. 选择剩余交易日严格超过40日、且到期最近的实际IM合约。以开仓后第40个交易日作边界，到期日须晚于该边界。
  4. 开仓后持有20个交易间隔，在第20个持有日之后的下一交易日开盘平仓。例如7月30日开仓，对应8月27日平仓。
  5. 初始本金1亿元，每笔保证金预算1200万元；按合约开盘价与保证金率计算整数手数，持仓规模随每笔开仓价变化。
  6. 开平仓各收取成交额万分之0.3手续费，持仓期间按实际合约收盘价估值；空仓资金收益取零。
手数 = floor[12,000,000 ÷ (开仓价 × 200 × 保证金率)]
净收益 = 手数 × 200 × (平仓开盘价 − 开仓开盘价) − 双边手续费

原文明确了信号、持有期、资金占用和手续费。保证金率、重复信号处理与绩效公式则需要结合外部规则和结果核验：本项目采用2023年5月5日前15%、此后12%的IM开仓保证金率；持仓期间形成的大跌信号，仍可在平仓后完成企稳确认；最后一笔交易须在样本截止日前完成20日持有。

年化收益采用净值几何增长率，年度交易日取250；年化波动采用日净值收益的样本标准差乘√250；夏普为（年化收益−2%）/年化波动；最大回撤为每日净值相对历史高点的最大跌幅。这组公式在四个指数和25组参数上同时接近原表。

3. 数据从哪里来，关键差异怎样找到

指数开高低收来自中证指数公司，交易日历取国证指数官方日线日期。期货行情采用新浪的逐合约历史日线，保留IM2303、IM2406等真实交割合约。原研报使用天软数据；这里通过公开数据重建同一套交易过程。

排查过程中，最明显的偏差出现在2022年底至2023年初。若全程固定12%保证金，早期仓位偏大，企稳策略期末净值会达到1.77689。中金所的历史规则显示，IM上市时保证金为15%，2023年5月4日交易后调整为12%。修正后，前两笔交易手数分别从80、78手变为64、62手，早期净值平台与原图对齐，期末净值降至1.74507。

中银国际期货完整转发的中金所发〔2023〕28号通知列出了IM保证金15%→12%的变化与生效时点。另用中金所官方日行情CSV核对IM2303的2022年12月23日、2023年1月4日、1月30日和2月8日，四天的开盘与收盘共8个价格均与新浪一致。

合约期限边界也影响结果。例如2022年10月21日，严格“超过40个交易日”对应IM2303；把边界放宽到40日会改选IM2212。最终采用严格边界，既符合原文，也与原图早期平台及整张参数表一致。

6. 如何从零运行

python -m pip install -r requirements.txt
python download_data.py
python reproduce.py
python check_results.py
python build_report.py

下载脚本保留原始文件及来源URL；回测脚本生成每日净值、全部交易、四指数绩效和参数矩阵；回测与核验脚本检查8个官方价格、两笔原文锚点、两次未来行情截断和参数矩阵误差；最后由本次输出生成这份HTML。原始数据保存在data/raw，计算输出保存在outputs。详细运行说明见同目录README。

本次覆盖研报中的期货主策略、直接抄底对照、25组参数与四指数比较。原文另有平值看涨期权对照，复现该部分需要逐执行价历史报价。
