# 大跌后的入场筛选

[完整报告](REPORT.html) · [原研报复现](../README.md)

本项目在华泰期货研报的七日企稳条件上，增加下行压力衰减和连续三日守底。

## 主回测结果

2022-07-22至2026-08-31，初始资金1亿元，保证金上限1200万元。

| 策略 | 笔数 | 年化收益 | 最大回撤 | 夏普 | 平均名义敞口 |
|---|---:|---:|---:|---:|---:|
| 原企稳条件 | 15 | 14.93% | 6.63% | 1.331 | 29.01% |
| 下行压力衰减 | 14 | 15.05% | 6.56% | 1.371 | 27.02% |
| 连续3日守底 | 14 | 15.43% | 6.63% | 1.425 | 27.03% |
| 双因子组合 | 13 | 15.55% | 6.56% | 1.468 | 25.04% |

## 因子与交易规则

P为确认日及此前两日的下行收益均方根，除以触发日前20日的同类指标，要求P≤1。正收益置零，均值包含全部窗口交易日。

A为确认日距触发日至确认日期间最后一次最低价的交易日数，要求A≥3；最低价并列时取最后一次。

原五日收益阈值−4.92%、七日确认、20日持有及双边各万分之0.3手续费继续用于主历史对照。手数按确认日已知价格取整，次日开盘按照预设限价执行；评估区间从首日开盘开始，读取前一收盘形成的订单，期末持仓按收盘估值。

## 时间留出与过拟合检查

训练区间2022-07-22至2023-11-30，仅用331个训练期五日收益估计5%分位数，阈值−4.396%。九组训练参数按夏普选择，至少要求三笔已平仓交易；选中P≤0.75、A≥3。

保留21个交易日的间隔后，测试2024-01-02至2026-08-31：

| 策略 | 年化收益 | 最大回撤 | 夏普 |
|---|---:|---:|---:|
| 同训练阈值基准 | 18.36% | 7.31% | 1.265 |
| 固定因子1.0/3日 | 19.04% | 7.31% | 1.364 |
| 训练选择0.75/3日 | 12.87% | 9.27% | 0.920 |

训练选择仅依靠3笔交易，守底2、3、4日的训练结果完全相同。逐年留出中，2024年与2026年选出的0.75阈值表现较弱，2025年选出的1.0阈值表现较好。报告保留全部结果。

因子构思参考了主回测区间的行情，结果按历史时间留出解释。报告另列2026年9月1日至11月9日的成交方式比较。

## 运行

先在上级目录安装`requirements.txt`并运行`download_data.py`，准备原研报数据快照。然后在本目录执行：

```bash
python fetch_evaluation_data.py
python backtest.py
python audit_validation.py
python build_report.py
```

原研报复现的数据位于上级`data/raw/`，补充行情位于本目录`data/evaluation/`，取数截至2026-11-09。

## 文件与结果

| 文件 | 作用 |
|---|---|
| `backtest.py` | 因子、确认日订单、开盘成交与撤单、逐日估值、主策略及跨指数等对照 |
| `fetch_evaluation_data.py` | 独立评估数据下载 |
| `audit_validation.py` | 时间留出、逐年检验、成交方式比较和回测检查 |
| `build_report.py` | 从回测输出生成报告 |
| `recent_year_check.py` | 单独计算近一年区间收益，输出保存在本地 |
| `REPORT.html` | 可离线阅读的因子研究报告 |

`outputs/`中的主要结果：`nav.csv`、`*_trades.csv`、`*_orders.csv`、`*_rejected.csv`、`metrics.json`、`audit.json`、`training_grid.csv`、`frozen_training_config.json`、`holdout.csv`、`holdout_nav.csv`、`walk_forward.csv`及`post_report_holdout.csv`。

原始数据和中间结果由Git忽略。仓库提交代码、README和一份HTML结果报告；单独区间的数值记录保留在本地输出目录。
