# 东吴证券国庆季节效应研报复现

复现东吴证券研究所2026年9月26日的正式策略周评《国庆假期的“季节效应”》。分析师：陈刚、林煜辉。[原始研报 PDF](https://pdf.dfcfw.com/pdf/H3_AP202609261829928887_1.pdf)。

研究对象为2006—2025年 A股国庆前后的宽基、风格及行业表现。主要结果见 [REPORT.html](REPORT.html)，下载后用浏览器打开即可，图表已内嵌。

## 结果

覆盖原文图3、图4中的32个指数，共256项统计：

- 128项胜率均与原表显示精度一致。
- 128项去极值收益均值中，120项与原表两位小数一致；均值最大差异0.03233个百分点，均方根误差0.00446个百分点。
- 国证、中证／上证、15个申万行业的216项统计全部在显示精度内对齐。
- 中信风格剩余8项均值差异在报告中逐项列出。

覆盖范围为17个风格／宽基、15个具有完整20年历史的行业，合计原表48个指数中的32个。原文Wind全A曲线、成交量曲线及微盘股指数的完整历史，属于继续扩展所需资料。报告另绘公开宽基的事件曲线，并单独观察2026年发表后收益。

## 运行

使用 Python 3.11—3.13，参考运行环境为 Windows、Python 3.13.9。Linux 绘图可安装 Noto Sans CJK 字体。

```bash
python -m venv .venv
```

Windows PowerShell 激活环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux/macOS 激活环境：

```bash
source .venv/bin/activate
```

在当前目录依次运行：

```bash
python -m pip install -r requirements.txt
python download_data.py
python run_research.py
python compare_paper.py
python build_report.py
```

下载程序使用国证、中证、中信和申万官方公开接口，保留正常 TLS 证书验证。首次下载约数十 MB。已有文件直接使用本地缓存；重新取得官方快照可运行 `python download_data.py --refresh`。数据请求参数、时间与校验摘要保存于 `data/manifest.json`。接口历史数据更新后，比较程序会重新报告实际差异。

## 计算口径

设 `t` 为每年10月1日之前最后一个交易日。原表标签与价格边界经11个完整历史宽基／风格指数联合核对后固定为：

| 原表标签 | 收益公式 | 收盘收益区间数 |
|---|---|---|
| T-10 | P[t] / P[t-11] - 1 | 11 |
| T-5 | P[t] / P[t-6] - 1 | 6 |
| T+5 | P[t+5] / P[t] - 1 | 5 |
| T+10 | P[t+10] / P[t] - 1 | 10 |

收益以百分数存储。胜率使用全部有效年份，收益均值剔除一个最大值、一个最小值。零收益计入胜率分母。每年的真实日期见 `event_dates.csv`；常规节前10／5个区间的统计另存为 `standard_window_stats.csv`。

国证2000的公开历史有16个有效国庆年份。节前按16年计算；节后将缺失4年按零计入20年，能够还原原表。这是基于表内数字反推的处理，代码只在“原表对齐统计”加入零观察。真实价格与逐年收益保留缺失，16年有效样本统计另存并在报告展示。

15个行业按四个窗口都覆盖20年这一条件选取。其余15个申万行业也下载并记录历史起点，方便补充资料后继续研究。

## 文件与输出

| 文件 | 用途 |
|---|---|
| `catalog.py` | 原件、指数、固定日期窗口清单 |
| `download_data.py` | 下载原件与47个指数的官方历史 |
| `run_research.py` | 交易日定位、逐年收益、原表与有效样本统计 |
| `compare_paper.py` | 从PDF提取原表并逐项核对 |
| `build_report.py` | 生成自包含中文结果报告 |
| `REPORT.html` | 一份结果报告，含图表与完整比较表 |

本地运行后生成：

| `outputs/` 文件 | 内容 |
|---|---|
| `prices.csv` | 按实际交易日历对齐的收盘点位 |
| `coverage.csv` | 每个指数历史起止、样本覆盖及入选情况 |
| `event_dates.csv` | 2006—2026年四个窗口的真实起止日期 |
| `event_returns.csv` | 各指数每年各窗口收益及常规窗口收益 |
| `reference.csv` | 从原始PDF提取的48行原表数字 |
| `source_stats.csv` | 用于原表对齐的32个指数统计 |
| `valid_stats.csv` | 仅使用有效年份的统计 |
| `standard_window_stats.csv` | 常规节前10／5个区间的敏感性结果 |
| `window_boundary_audit.csv` | 11个完整指数两种节前边界的联合核对 |
| `comparison.csv`、`validation.json` | 全部256项误差和汇总 |
| `event_paths.csv`、`stability.csv` | 补充事件路径与分段统计 |

均值精度检查线为0.00501个百分点，中信组另以0.04个百分点作为重复运行报警线；胜率按整数百分比精度核对。报告同时展示实际误差、显示精度吻合数及剩余差异。原始数据和中间结果由代码生成，仓库保留代码、README和结果报告。
